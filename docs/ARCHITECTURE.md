# Arquitetura

## Ponto de partida

- Frontend: React + Vite + TypeScript em `frontend/`.
- Dados e autenticação: Supabase.
- Edge Functions: TypeScript/Deno em `supabase/functions/`, se necessárias.
- Backend separado: opcional em `backend/`; definir linguagem e framework somente se o desafio exigir.

Atualize este documento quando a arquitetura do MVP for decidida.
