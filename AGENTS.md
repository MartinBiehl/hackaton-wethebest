# Instruções para agentes

Antes de alterar o projeto, leia `README.md` e os documentos de contexto, arquitetura, tarefas, decisões e fluxo Git em `docs/`.

- Confirme com a equipe a tarefa e os arquivos envolvidos; não trabalhe simultaneamente nos mesmos arquivos que outra pessoa ou agente.
- Siga `docs/GIT_WORKFLOW.md`: use uma branch por tarefa e não altere `main` diretamente.
- Mantenha os documentos de contexto atualizados quando uma decisão do projeto mudar.
- Nunca grave credenciais ou chaves secretas no código, no frontend ou no Git.
